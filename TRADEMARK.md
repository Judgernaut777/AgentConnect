# Trademark policy

The Connect project code is open source under the Apache License, Version 2.0
(see [LICENSE](LICENSE)). This document covers something the license does not:
the project's **names and marks**.

## The marks

"Connect", the Connect product names — **AgentConnect**, **BrainConnect**,
**ToolConnect**, **ComputeConnect**, **Connect-Governance**, **Connect-Control** —
and any associated logos are common-law trademarks of the Connect project
(Judgernaut777). They are *not* licensed under Apache-2.0.

## What you may do

- Refer to the project and its products by name in text, talks, articles,
  benchmarks, and compatibility statements ("works with ToolConnect",
  "built on AgentConnect") — nominative fair use, always welcome.
- Fork, modify, and redistribute the code under Apache-2.0, including
  commercially, provided you follow the license terms.
- State truthfully that your product integrates with, is compatible with, or
  is derived from the Connect ecosystem.

## What you may not do

- Use the marks as the name of your own product, service, company, or domain
  (e.g. "AgentConnect Cloud", "toolconnect.io") in a way that suggests your
  offering is the official project or is endorsed by it.
- Operate a hosted or managed service under any of the marks. If you offer a
  hosted derivative, give it your own, clearly distinct name and say honestly
  that it is derived from Connect.
- Use the marks in a marketplace listing, package name, or repository name in
  a way likely to confuse users about origin or endorsement.
- Register the marks (or confusingly similar ones) as trademarks, domains, or
  app-store names in any jurisdiction.

## Why

The ecosystem's value proposition is trust: audited work, human-gated memory,
fail-closed authorization, and documentation that cannot drift from reality.
That only works if users can tell the official, verified artifacts from
unrelated ones. The code is free; the name is how users know what they are
running.

## Questions and permissions

If you want to use the marks in a way this policy does not clearly permit,
open an issue in the relevant repository and ask. Reasonable requests —
community events, distributions, integrations — will generally get a fast yes.

the Apache Software Foundation. It may be revised; the version in the Connect
umbrella repository (github.com/Judgernaut777/Connect) is canonical.*
